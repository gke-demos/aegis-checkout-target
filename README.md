# aegis-checkout-target

Companion target repository for [gke-demos/agent-security](https://github.com/gke-demos/agent-security) (AegisSRE).
Used by AegisSRE's live GitHub connector to inspect `checkout-service` code, read incident issues, run untrusted verification tests inside an Agent Substrate gVisor sandbox, and open remediation Pull Requests gated by ADK v2 Step-Up Confirmation.
